# react-native-vega-mcp-bridge

**Apache-2.0 Open-Source SDK for Fire TV & Vega OS, Alexa+ Streamable HTTP MCP, Ring WebRTC WHEP, and Bee Ambient Memory.**

## Why It Matters
Building multi-modal 10-foot experiences on **Fire TV (Vega OS & Fire OS)** requires deterministic spatial focus management (`TVFocusGuideView` / `FocusManager`), strict WebRTC WHEP SDP signaling for **Ring (Amazon Vision)** streams, and schema normalization for **Alexa+ MCP Apps** and **Bee Wearable** endpoints. This package provides tested, zero-boilerplate primitives for the Amazon Developer ecosystem.

## Quick Verification

    npm install
    npm test
    npm run build
